# Fantasy Sports App

## Programming 3 Coursework

### Overview

This application is a Scala-based console program developed for Programming 3 Coursework 2. It analyses fantasy sports player data using functional programming techniques. The program reads player scores from a file and allows the user to perform a range of analyses through a menu-driven interface.

---

### Features

- View current week scores for all players  
- Display highest and lowest scores  
- Find players with total points over 500  
- Compare average scores between two players  
- Calculate custom team scores up to a selected week

---

### Tech

- Scala  
- Functional programming (pure functions, higher-order functions)  
- Immutable data structures  
- Error handling with Try and Either
